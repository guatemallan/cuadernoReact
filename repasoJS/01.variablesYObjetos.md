### Objetos

[Ver apuntes en cuadernoJS](https://github.com/guatemallan/cuadernoJS/tree/main/08.objetos)

En JS todo es un objeto! Un objeto es una colección de propiedades. Una propiedad es una asociacion de una llave y un valor. 

```
const producto = {
    nombre : 'Tablet',
    precio : 300,
    disponible : false   
}
```

#### Sintaxis de punto en objetos
Se usa para acceder al valor de una llave (propiedad) de un objeto.
`console.log(producto.nombre)`
`console.log(producto.precio)`

#### Destructuring
Notación moderna para acceder a una propiedad en un objeto. Su objetivo es reducir la escritura de código.

`const { nombre } = producto` es equivalente a `const nombre = producto.nombre`

En sintáxis tradicional, para extraer todas las propiedades de *producto* tendria que hacer 3 variables:

```
const nombre = producto.nombre
const precio = producto.precio
const disponible = producto.disponible
```

Con destructuring se simplifíca el código:

```
const { nombre, precio, disponible } = producto

```

#### Object literal
Asociación de variables a un objeto. Útil para agrupar resultados. Solo se puede aplicar cuando las variables a asociar tienen el mismo nombre que las llaves del objeto. 

```
const usuario = 'Juan'
const autenticado = false

const nuevoObjeto = {
    usuario : usuario,
    autenticado : autenticado
}
```

Este código se puede resumir en:

```
const usuario = 'Juan'
const autenticado = false

const nuevoObjeto = {
    usuario,
    autenticado
}
```
#### Manipulación de objetos
Cambiar los valores de un objeto.

```
const producto = {
    nombre : 'tablet',
    precio : 300,
    disponible : false
}
```

> Cambiar el valor de una propiedad
`producto.disponible = true`

> Agregar una propiedad nueva
`producto.imagen = 'imagen.jpg'`

> Eliminar una propiedad
`delete producto.imagen`

>##### Object Freeze
> Bloquea cualquier modificación de un objeto, incluyendo valores y propiedades:
`Object.freeze(producto)`

>##### Object seal
> Similar a freeze, pero en este caso solo se bloquean los valores:
`Object.seal(producto)`

#### Destructuring de dos o mas objetos

Suponiendo que tengo estos dos objetos:
```
const producto = {
    nombre : 'tablet',
    precio : 300,
    disponible : false
}

const cliente = {
    nombre = 'Juan',
    apellido = 'Valdez'
}
```

Si trato de hacer deestructuring con ambos de la siguiente manera, tendre un error:

```
const { nombre } = producto
const { nombre } = cliente
```

El error viene de que el interprete está intentando crear 2 variables `nombre` para asignarles el valor de ambos objetos. Para evitar esto:

```
const { nombre } = producto
const { nombre: nombreCliente } = cliente
```

En este caso, renombra la segunda variable a `nombreCliente`. Esto puede ser util cuando se usan dependencias o librerias, que tienen variables con el mismo nombre, por ejemplo `data`.

#### Destructuring de objetos anidados

Tomando como base el siguiente objeto:
```
const cliente = {
    nombre = 'Juan',
    apellido = 'Valdez',
    direccion {
        calle : 'Calle México',
        numero : 8007 
    }
}
```

Si trato de hacer destructuring de la siguiente manera, el resultado en la variable será el objeto `direccion` dentro de la variable `calle`:

```
const { nombre: nombreCliente, direccion: calle } = cliente

console.log(nombreCliente)
console.log(calle)
```

Resultado en la consola:

  ---
  Juan
  ---
  ▸ {calle: 'Calle México'}
  ---

Para prevenir esto: 

```
const { nombre: nombreCliente, direccion:  { calle }} = cliente

```

Resultado en la consola:

  ---
  Juan
  ---
  Calle México
  ---

#### spread operator
Unir dos o mas objetos. Suponiendo que tengo estos objetos:

```
const producto = {
    nombre : 'tablet',
    precio : 300,
    disponible : false
}

const cliente = {
    nombre = 'Juan',
    apellido = 'Valdez'
}

const carrito = {
    cantidad : 1,
    producto
}

console.log(carrito)
```

En la consola, el resutlado sera:
```
    ▸ {cantidad: 1, producto: {]...}}{
        cantidad: 1
        ▸ producto: {nombre: 'Tablet', precio: 300, disponible: false}
        ▸ [[Prototype]]: Object
    }
```

Si en cambio reescribo el objeto `carrito` asi:

```
const carrito = {
    cantidad : 1,
    ...producto
}

console.log(carrito)
```

En la consola, el resutlado sera:
```
    ▸ {cantidad: 1, nombre: 'Tablet', ...}{
        cantidad: 1
        nombre: 'Tablet'
        precio: 300,
        disponible: false}
      ▸ [[Prototype]]: Object
    }
```

Agregando varios objetos:

```
const nuevoObjeto = {
    producto: {...producto},
    cliente: {...cliente}
}
```

Aplicando objecto literal:
```
const nuevoObjeto = {
    producto,
    cliente
}
```

Si aplico el *spread operator*, todas las propiedades seran del `nuevoObjeto`, excepto nombre que al estar en ambos objetos, el nombre del producto será reescrito.
```
const nuevoObjeto = {
    ...producto,
    ...cliente
}
```

Para simplificar aún más el código, se puede utilizar la función `Object.assign`:

` const nuevoObjeto2 = Object.assign(producto, cliente)`
